# 言墨输入法 (yanmo-ime) 交互设计规范

本文档详尽规范言墨输入法在实际日常输入中的按键映射、界面状态机与手势/触控行为。

---

## 1. 核心交互理念：键盘盲打与触屏视觉双轨协同

为了兼顾高速盲打打字节奏与 Surface 触屏/高分辨率屏的查字便利性，言墨确立如下双轨机制：

| 操作路径 | 触发方式 | 适用场景 |
| :--- | :--- | :--- |
| **键盘盲打流** | `Tab` 键（辅码模式） | 日常高速打字、双手留在键盘主键区 |
| **视觉触控流** | 候选框右上角 `[部首 ▾]` 按钮 | 遇到生僻字、查字或不确定部首读音时 |
| **语音流** | 全局快捷键（如 `Super + V`） | 长文本速记、双手不便敲击键盘时 |

---

## 2. 状态机与按键行为

```text
       [ 空闲状态 (Idle) ]
               | 键入 a-z
               v
     [ 拼音组合状态 (Composing) ] <----------------+
          /           \                            |
   按 Tab/`            按 1-9/Space (选词上屏)       | 按 Backspace
        /               \                          | 退回拼音状态
       v                 v                         |
[ 部首过滤 (Radical) ]  [ 字符上屏 -> 返回 Idle ]   |
       |                                           |
       +-------------------------------------------+
```

## 3. 详细交互示范

### 3.1 基础拼音输入与选词
- **按键输入**：连续输入拼音字母，例如键入 `zhongwen`。
- **候选条展示**：
  ```text
  zhongwen_
  1.中文  2.仲温  3.中温  4.钟文
  ```
- **选词确认**：
  - 按 `空格` 或数字键 `1`：默认选中首选词 `中文` 上屏。
  - 按数字键 `2-9`：选择对应项上屏。
  - 按 `=` / `-` 或 `PageDown` / `PageUp`：前后翻页。

---

### 3.2 部首过滤模式 (Tab 辅码流)

当输入的拼音存在大量同音字/词，难以快速翻页时，激活部首过滤：

1. **进入部首模式**：
   - 输入拼音 `he`：
     ```text
     he_
     1.和  2.合  3.河  4.何  5.核  6.喝  7.荷  8.禾 ...
     ```
   - 按下 **`Tab`** 键（或备选反引号 `` ` `` / `~` 键），输入条切换状态：
     ```text
     he [部首: _]   [部首 ▾]
     提示: 输入部首拼音 (例: shui -> 氵部)
     ```
2. **输入部首拼音**：
   - 键入 `shui`（代表“水/氵”部）：
     ```text
     he [部首: shui (氵/水)]   [部首 ▾]
     1.河  2.涸  3.渮  4.菏
     ```
   - 候选字列表瞬间缩小为仅包含水部的汉字！
3. **完成上屏**：
   - 按 `空格` 或对应数字键，`河` 字上屏，状态自动重置为空闲。
4. **退出部首模式**：
   - 按 `Backspace`：删除部首字符；若部首已清空，再次按 `Backspace` 恢复至普通拼音编辑状态。
   - 按 `Esc`：清空当前所有未上屏字符，直接退回空闲状态。

---

### 3.3 视觉触控流 (Surface 触屏与鼠标)

在候选条右上角常驻一个半透明精致的下拉指示按钮 `[部首 ▾]`：

1. **展开面板**：
   - 鼠标点击或手指轻触 `[部首 ▾]`。
   - 候选框下方立即展开 **常用部首速查九宫格**（按笔画排序）：
     ```text
     ┌──────────────────────────────────────────────────┐
     │ 常用部首:                                        │
     │ 一画: 一 丨 丿 丶 乙                               │
     │ 二画: 十 厂 匚 卜 冂 八 人 勹 几 儿 冫 凵 刀 力 又   │
     │ 三画: 口 囗 土 士 夂 夕 大 女 子 寸 小 尢 尸 山 巛 巾│
     │       犭 弓 彳 氵 彡 艹 辶 忄 门 宀              │
     │ 四画: 木 欠 止 歹 殳 毋 比 毛 氏 气 水 火 爪 父 牛 犬│
     │ ...                                              │
     └──────────────────────────────────────────────────┘
     ```
2. **快速选择**：
   - 点击具体部首（如 `木`），当前候选词列表立即联动过滤为木部汉字。

---

### 3.4 语音输入交互 (Voice Dictation)

- **快捷键**：全局 `Super + V`（Windows/Command 键 + V）或 `Ctrl + Alt + V`。
- **模式 A（长按即说，Push-to-Talk）**：
  - 按住快捷键不放：屏幕中央浮现精致录音波纹动画提示 `[ 🎙️ 正在倾听... ]`。
  - 说话完毕松开按键：动画转为 `[ ⚡ 识别中... ]`，100ms 内文本自动键入当前获得焦点的应用中。
- **模式 B（单击启停，Toggle）**：
  - 单击快捷键开始录音，再次单击结束并上屏。

---

### 3.5 词条管理与自学习
- **词频调整**：用户高频选中的候选词，自动前移至第 1 位。
- **删除错词**：在候选列表中，光标移动到某候选词后，按下 `Shift + Delete`，即可从个人自学词库中彻底抹除该词条。
